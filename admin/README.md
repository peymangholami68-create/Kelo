# KELO Admin

پنل مدیریت با همان حساب کاربری و با `System Role` جداگانه کار می‌کند. نقش تجاری «کشاورز/ماشین‌دار» برای حساب وجود ندارد.

در این مرحله، Backend احراز هویت و Session واقعی را پشتیبانی می‌کند. UI مدیریت فعلی داخل `index.html` باقی مانده است و در مرحله بعد به `/admin` مستقل منتقل می‌شود.
